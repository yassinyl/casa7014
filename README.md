## 🚀 Installation

### CasaOS — AppStore V1

1. Open your CasaOS dashboard.
2. Go to **App Store**.
3. Select **Add Source**.
4. Enter:

```text
https://cdn.jsdelivr.net/gh/yassinyl/casa7014@gh-pages/casa7014.zip
```

5. Click **Add**.

---

### ZimaOS — AppStore V2

1. Open the ZimaOS App Store.
2. Add a **Community App Store**.
3. Enter:

```text
https://cdn.jsdelivr.net/gh/yassinyl/casa7014@gh-pages/store.json
```

4. Click **Add**.
